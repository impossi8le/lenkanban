# Инвентарь исходников для сборки

Список перечисляет воспроизводимый пакет исходников приложения. Он не является подтверждением выкладки на сервер. Локальные секреты, рабочие данные и служебные отчёты конкретной установки не входят в пакет. Полная документация публичного проекта находится в README и docs/.

Канонические e2e/baselines/**/*.png включаются вместе с соответствующими .png.json после проверки хеша и происхождения. Эти проверки не доказывают полную visual-матрицу или браузерную приёмку.
