## Проверка и границы результата

Проверяются наличие рабочих документов, локальные ссылки в текущих Markdown-документах вне блоков кода, покрытие исторических/вложенных файлов предупреждениями и соответствие описанных команд package.json. GitHub-задачи #1–#11 перечитаны через коннектор после создания. Внешние ссылки, заголовочные якоря и архивные ссылки на отсутствующие артефакты не являются частью проверки локальных путей.

При первоначальном документационном аудите приложение, unit/E2E-тесты, сборка, почтовый сервер и production не запускались; продуктовый код не менялся. Позже добавлены почтовые инструменты и выполнены их проверки на синтетических данных, запущены локальные Next.js и Socket.IO. Полный прогон тестов приложения и production по-прежнему не подтверждены. Пароли, токены, письма и реальные вложения в задачи не переносились.

Рабочий каталог не содержит .git. В приватном репозитории GitHub опубликованы задачи и документация; исходники приложения остаются локальными. Рабочие этапы ведутся в поле Status [нативного GitHub Projects](https://github.com/users/impossi8le/projects/6/views/1), а правила и справки — в Git. Настройки проекта хранятся в интерфейсе GitHub. Исправление доски и итоговая проверка публикации учитываются в открытой [#28](https://github.com/lenremont2/kanban_pochta/issues/28); сейчас она находится «На тестировании». ## Последующее состояние реализации 20.10.2026

[Сборщик](MAIL_COLLECTOR.md) поддерживает отдельный профиль входа, инспекцию DOM, возобновление, учёт ошибок и консервативный статус охвата. Первая [живая проверка](MAIL_LIVE_VALIDATION.md) подтвердила селекторы и собрала 2 темы / 2 сообщения из отфильтрованного списка. Это не ограничение прав аккаунта. После «Показать все темы» подтверждены 20 тем на странице, пагинация до 2630 и счётчик 52 594, единица которого не установлена. Выгрузка всего архива не подтверждена: `unverified`. [Классификатор](MAIL_CLASSIFICATION.md) обработал только прежние две записи, обе unmatched. Сборщик явно выбирает все темы и сохраняет отдельный checkpoint фильтра. Код опубликован в draft PR #29, без слияния в main; #21 и #23 остаются «В работе».

Для инструментов нужен Node.js 24; Docker не требуется. Локальное приложение работает: [регистрация](http://localhost:3555/sign-up), Socket.IO 3556, [Mailpit](http://localhost:8025), PostgreSQL в Docker. Применена локальная Prisma-схема. Пройдены 9 проверок API, включая регистрацию, доставку и подтверждение письма, сессию входа, создание/чтение проекта и колонок. Это заменяет прежнюю блокировку Docker/WSL; полный UI и production не проверены.

Публикация: [draft PR #29](https://github.com/lenremont2/kanban_pochta/pull/29), ветка `codex/mail-collection-2026-10-20`. Состав PR включает инструменты, синтетические тесты и документацию; 78 тестов прошли. Сырые письма, профиль и локальные результаты не включены. Слияние в `main` не выполнялось, #21 и #23 остаются «В работе».


Сбор через встроенный браузер: [инструкция](MAIL_IAB_COLLECTION.md), [контроль охвата](MAIL_IAB_COVERAGE.md), [методика группировки и предложений досок](MAIL_KANBAN_FINDINGS.md).
