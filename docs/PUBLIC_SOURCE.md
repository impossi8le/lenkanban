# Публичные исходники

Этот репозиторий содержит полный исходный код приложения, схему и миграции Prisma, тесты, синтетические визуальные эталоны и инструменты сборки. История публичного репозитория начинается с проверенного снимка проекта.

Локальные окружения, ключи доступа, рабочие данные, резервные копии, журналы и служебные отчёты конкретного сервера в состав исходников не входят. Примеры окружения предназначены для отдельной локальной установки. Производственные доменные ограничения в коде сохранены как часть поведения приложения.

Документы в `docs/` включают исторические планы и результаты проверок. Их даты и формулировки относятся к соответствующему этапу разработки. Актуальная точка входа для публичного репозитория — [README](../README.md).
