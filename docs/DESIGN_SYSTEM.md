# Ленканбан: дизайн рабочего пространства

Сверено с исходниками 20.10.2026. Визуальная проверка в браузере в этой сверке не выполнялась.

## Направление

Спокойный, плотный интерфейс для ежедневной работы команды. Нейтральная поверхность доски, отдельный уровень карточек и меню, синий акцент для действий. Цвет приоритета дополняет текстовую подпись. Никаких перемещений карточки при наведении: геометрия должна оставаться стабильной для drag-and-drop.

## Источники

- [Atlassian Design: color](https://atlassian.design/foundations/color) — семантические токены и независимые темы.
- [Radix Colors: understanding the scale](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale) — отдельные роли поверхностей, границ и текста.
- [Anthropic frontend-design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) — осмысленная типографика, предметная композиция, сдержанное движение.

## Контракт

`src/app/design-system.css` — источник токенов. У текста на основной и опасной кнопке всегда свой foreground, поскольку в тёмном режиме заливка становится светлее. Обычный текст >= 4.5:1; границы полей >= 3:1. Автотест проверяет 32 пары, но не заменяет проверку итогового DOM и прозрачных наложений.

Карточки: радиус 10px, минимальная тень, цвет приоритета в метке и боковом маркере. Колонки: нейтральный пониженный слой, счётчик tabular-nums, действие добавления 44px. Интерфейс использует установленный Inter с кириллицей; CSS теперь действительно подключает его через font-sans. Не добавляем новую библиотеку ради внешнего вида.

Состояния: hover меняет границу/заливку, focus видим, disabled сохраняет подпись. Reduced motion поддерживается провайдером Motion и CSS. Для системной темы иконка отражает resolvedTheme.

Визуальные эталоны и ограниченный бюджет измеренной вариации пикселей описаны в [контракте #60](engineering/VISUAL_REGRESSION_CONTRACT.md). Принятие бюджета не устанавливает причину вариации и не заменяет полную браузерную приёмку.

- `node node_modules/vitest/vitest.mjs run src/features/kanban/theme`
- Целевые регрессионные тесты DnD и представлений.
- Изолированный browser suite: см. [TESTING_KANBAN_DND_V2.md](TESTING_KANBAN_DND_V2.md); ручной протокол — [MANUAL_ACCESSIBILITY_TESTING.md](MANUAL_ACCESSIBILITY_TESTING.md).
- Встроенный браузер: вход, проекты, доска, таблица, календарь, карточка; светлая/тёмная/системная темы; узкий экран; клавиатура; сохранение предпочтения после reload.

Не считать весь продукт проверенным до прохода внутренних экранов в браузере. Production требует проверенной сборки и серверного развёртывания.

## Где реализовано

- Токены light/dark: [design-system.css](../src/app/design-system.css); итоговые стили: [globals.css](../src/app/globals.css).
- Inter (latin/cyrillic) и JetBrains Mono подключены через next/font в [layout.tsx](../src/app/layout.tsx).
- Компоненты общего назначения: `src/components/ui`; тема и MotionConfig: `src/providers/theme-provider.tsx`.
- [palette-contrast.test.ts](../src/features/kanban/theme/palette-contrast.test.ts) проверяет 15 пар текста и одну пару input/card для каждой темы (32 проверки), theme-contract — отдельные компонентные контракты. Здесь тесты перечислены, новый passing-результат не заявляется.
