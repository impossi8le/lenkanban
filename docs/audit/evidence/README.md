# Доказательства аудита

Сырые журналы и JSON-выгрузки исключены из публикуемого дерева по #81: они не являются исходниками и могут содержать рабочие данные. Исторические результаты и ограничения остаются в сводках [аудита](../README.md) и [функциональной проверки](../FUNCTIONAL_AUDIT.md).

Не добавлять сюда сырые логи, почтовые выборки, идентификаторы, внутренние ссылки и содержимое ответов API. Для будущих проверок используйте закрытый локальный каталог work/, публикуя только безопасную сводку. Удаление из текущего дерева не очищает историю Git и не означает повторную проверку приложения.
