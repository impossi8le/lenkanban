# Ускорение интерфейса и доставка новых обращений — 25.10.2026

## Требования и реализация

- Убрать из desktop/mobile меню «Сообщения», «Входящие», «Уведомления», «Аналитика». Колокольчик и браузерные уведомления сохраняются.
- Список отделов загружает редакторы создания и шаблонов только при открытии. У локальных ссылок карточек отключена автоматическая предзагрузка серверных detail-маршрутов; свежая проверка доступа при открытии обязательна.
- При первом открытии карточки оболочка загрузки появляется сразу, до получения динамического JS. Доступны закрытие, Escape и возврат фокуса.
- Добавление default view=board меняет URL без повторной серверной навигации; независимые политики доски вычисляются параллельно только после авторизации и проверки доступа.
- Действия исполнителя расположены над описанием. Права перечитываются при открытии, кеш lifecycle разделён по аккаунтам. На доске есть явный вход к действиям; переходы идут через существующий канонический API, без drag/drop и обхода прав.
- Частный DRAFT не доставляется исполнителям. После submit первым разрешённым событием может быть task:updated: неизвестная доске заявка должна добавляться, а не отбрасываться. После восстановления соединения и возвращения во вкладку требуется ограниченное перечитывание канонического списка.
- Колокольчик сверяет счётчик после первого подключения к личной комнате и после повторного подключения: событие между первоначальным чтением и подпиской не должно теряться. Существующие серверные получатели, Notification и браузерный transport сохраняются.
- Формы имеют одинаковые горизонтальные отступы заголовка и полей; кнопки выбора отдела выровнены по нижнему краю, заголовки колонок имеют общую высоту при переносе текста.

## Границы проверки

Изолированные браузерные проверки используют настоящие UI-компоненты и синтетические session/API/socket. Они не доказывают работу авторизованного production-сеанса. Чтение production технических метаданных подтвердило: gzip и immutable cache статических chunks работают; ответственная группа активна, в ней 5 активных сотрудников; queue-уведомления сохраняются; внутренний app/socket secret совпадает и приватный сетевой transport разрешён. Значения секретов и содержимое обращений не выводились.

Миграции, seed/reset и изменение прав пользователей не требуются. Статус фактической публикации и проверок записывается отдельно в deploy/.
