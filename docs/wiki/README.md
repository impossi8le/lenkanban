## Как поддерживать вики

При изменении поведения обновлять соответствующий раздел, добавлять дату и ссылку на код или отчёт. Разделять исходники, наблюдаемое поведение и план. Исторические отчёты не переписывать под новое состояние. Не переносить `.env`, дампы, персональные данные, содержимое писем, токены и секреты доступа.
